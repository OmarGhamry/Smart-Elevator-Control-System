# Tests

Keep test scenarios, expected results, and verification notes in this directory.

Suggested initial scenarios:

- No pending requests: elevator remains idle.
- A request is made on the current floor.
- A request is made above the current floor.
- A request is made below the current floor.
- Multiple requests are pending in both directions.
- A door obstruction is detected.
- Emergency stop is activated.
- A floor sensor reports arrival.

Update these scenarios once the final requirements and controller behavior are agreed.
